# 📺 Netflix Data Analysis

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

The analysis focuses on identifying content trends, top-performing genres, country-wise content distribution, ratings, and yearly/monthly additions.

---

## 🔍 Key Business Insights

- Movies significantly outnumber TV Shows.
- International Movies dominate Netflix's catalog.
- The United States contributes the largest number of titles.
- TV-MA is the most common content rating.
- Netflix added the highest number of titles in 2019.
- July and December recorded the highest number of content additions.
